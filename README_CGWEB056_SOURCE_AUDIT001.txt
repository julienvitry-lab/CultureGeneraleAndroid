CGWEB056 - SOURCE_AUDIT001
=============================
Audit en lecture seule des sources de questions :
- couverture par URL ;
- questions sans source ;
- URL invalides/non HTTP(S) ;
- URL HTTP non chiffrées ;
- classement des domaines les plus utilisés ;
- export CSV et ouverture de la fiche concernée.
Réutilise le catalogue chargé par CGWEB055 et n'effectue aucune requête destructrice.
